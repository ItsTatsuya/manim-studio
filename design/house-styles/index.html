House styles for lesson videos

Six styles are locked in. Four more options follow for review. Each style is a complete engine theme: ten colour roles, four font roles, type sizes, layout and pacing. Every field matches manim::theme::Theme, so any of these can go straight into crates/studio-render/src/style.rs. All fonts are SIL Open Font License, so they can be bundled with the app and burned into exported video.

Shipping notes

The handwriting font is not bundled today

All four current styles name Caveat for the hand role, but crates/studio-ui/assets/fonts only holds Inter, Inter Display and JetBrains Mono. On a machine without Caveat, annotations fall back to a system face. Whatever styles ship, bundle their hand fonts.

What happens to the current four

  • Chalk → Slate (locked)
  • Grid → Clean (locked)
  • Paper → Whiteboard (locked)
  • Night → Phosphor (locked)
  • Playground and Documentary are new additions.

Variable fonts are fine

The engine sets a variable font's wght axis to the weight it asks for, so most families ship as one variable file. Titles are drawn at 600, headings at 500 and handwriting at 600, whatever the style; a static family snaps to its nearest weight.

Possible engine additions

  • fonts.heading_weight: titles are always 600 today, so Plus Jakarta Sans can't reach its intended 800.
  • fonts.math_family: let Documentary typeset equations in a matching serif.
  • layout.title_case: some styles read better with sentence case enforced.
