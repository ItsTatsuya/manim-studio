Natural-sounding narration, cleaner videos and new house styles with high-quality fonts.

## What's changed

- feat(narration): speak paragraphs as one passage and time the animation to the voice, removing long pauses and choppy breaks
- feat(styles): seven redesigned house styles set in bundled Google Fonts, with new Clean (default), Editorial, Midnight and Blueprint
- feat(styles): preview a style before choosing it, and pick heading, body and code fonts per project, including uploaded fonts
- feat(video): generated videos keep slides centred, fade old content out before new content appears, and avoid overlapping text
- feat(queue): see what is rendering, being fixed and waiting from the Queue button beside Render
- feat(watermark): make a project's watermark the default for every project in one step
- perf(render): text with custom fonts renders many times faster on Windows
- feat(narration): new projects use the High quality voice, or Standard when only that model is downloaded
- fix(web): dropdowns open without a bounce, and font lists match the rest of the app
- fix(web): the Preview panel no longer jumps when switching between chats
- fix(web): the video preview shows its details, Loop, folder and Save actions in one tidy card
- fix(web): the default style is listed once in style pickers
