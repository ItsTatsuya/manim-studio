# Manim Studio 1.0.0 — First release

Create narrated Manim animations in one Windows workspace.

- A T3 Code-style React workspace with project chats, a streamed agent timeline,
  resizable project panel, render history, and a collapsible sidebar.
- Managed Codex and Claude Code CLI sessions with login diagnostics, binary
  overrides, model selection, custom models, resume, and process-tree cancellation.
- First-run setup detects installed assistants, opens their installation or login
  windows, and explains references, generation, narration, rendering and export.
  Reopen it from Settings â†’ General.
- Generate Manim scripts, natural spoken narration, and SVG or Pillow assets in
  one chat. Validate scenes before optional automatic rendering.
- Local Kokoro voice preview, sentence pauses, spoken-text normalization, boundary
  fades, and loudness mastering.
- Reference document uploads with a visible attachment menu, progress, retry,
  Windows file dialogs for documents and media, and protection against sending
  before files finish uploading.
- Locally bundled Poppins for the interface and Geist Mono for code; aligned
  narration controls and clear selected tabs without layout movement.
- Serialized autosaves, failed-save draft recovery, and save-before-close handling.

The Windows packages include Python 3.12, Manim Community 0.21.0, Cairo, shared
WebView2 support, minimal LaTeX, Typst, and audio tools. Codex and Claude Code
are installed separately and use their existing account login. Voice models
download on demand.

Download Setup for an internet-assisted installation, Offline Setup for bundled
rendering tools, or extract the entire Portable ZIP and open Manim Studio.exe.
The matching third-party sources, original licenses, source manifest, and SHA256
checksums are provided alongside the builds.

Validation: 163 Python tests, 23 browser tests with real narration and rendering,
real Windows file-dialog selection/cancellation checks,
and accessibility/layout checks across 14 views in both themes at three sizes.
Packaged native UI, math, Typst, audio, payload inventories, ZIP CRCs, source
parity, and release checksums are verified before publication.

Document uploads were tested before packaging; see the
[verification report](../document-upload-verification.md). Live Codex reference
generation and narrated rendering passed. Live Claude document generation and the
scene check also passed after its initial account quota reset.
