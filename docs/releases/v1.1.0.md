Manim Studio 1.1.0 keeps standard LaTeX compatibility, adds Typst equations, and substantially reduces the Windows app footprint.

## What changed

- **Smaller app:** approximately 695 MB of shipped files instead of 1.62 GB; the portable ZIP is approximately 263 MB instead of 655 MB.
- **Shared Evergreen WebView2:** Studio uses Microsoft's shared browser runtime instead of shipping a private 701 MB copy. Setup prepares WebView2 when missing; the offline installer includes its full prerequisite.
- **Minimal TeX plus Typst:** existing `Tex` and `MathTex` scripts keep standard LaTeX support. `Typst` and `MathTypst` are available for new scripts. LaTeX DVI and pdfLaTeX PDF equation paths are verified.
- **Safer preparation:** online setup embeds the reviewed TeX snapshot, verifies every file, and downloads hash-locked Python packages. Prerequisite failures leave the existing app and saved work untouched.
- **Updates and documentation:** portable update validation supports the new runtime layout. The README is shorter and includes a fresh screenshot of real rendering in Studio.

The editor, render controls, audio tools, native video playback, history, and saved preferences remain available. The shipped-file measurement excludes user data, generated caches, and the shared WebView2 installation; a machine without WebView2 still needs that runtime.

## Downloads

- **Setup-x64.exe:** downloads the rendering engine during setup; internet required.
- **Offline-Setup-x64.exe:** includes rendering tools and the Evergreen prerequisite for offline installation.
- **Portable-x64.zip:** extract the entire ZIP and open **Manim Studio.exe**. First launch needs internet if WebView2 is absent.
- **Third-Party-Sources.zip:** matching component sources and original build recipes, including Typst's native Rust dependencies.
- **SHA256SUMS.txt:** SHA-256 checksums for the four downloads.

Online setup's initial download is larger than v1.0.0's 5.2 MB bootstrapper because the verified TeX snapshot is now included. Python packages are downloaded separately. Only the minimal TeX plus Typst edition is published in this release.

## Upgrading from v1.0.0

Installed users can run setup or use **Updates**. Saved scripts, assets, preferences, and renders are preserved.

**Portable users must migrate manually once:** the old updater expects a private browser and cannot install this new ZIP layout. Close Studio, extract the complete v1.1.0 ZIP into a fresh folder, copy the old `UserData` into the new folder, and open the new executable. Keep the old folder until you have checked your saved work. Later updates use the new helper.

## Requirements and limits

Requires 64-bit Windows 10 (2004+) or Windows 11. Studio executables remain unsigned. Scripts execute with your Windows account's permissions.

The included TeX profile supports standard Manim equations but excludes XeLaTeX, LuaLaTeX, bibliography processing, and general publishing utilities. Custom workflows may require a separate full TeX installation. Typst uses its own syntax; existing LaTeX scripts do not need conversion in this edition.
