Manim Studio's first public release is a local Windows desktop app for editing Manim scripts, rendering animations, and previewing videos in one workspace. No Python installation, account, or command-line workflow is required.

## Included

- **Editor:** Python highlighting, autocomplete, formatting, script import/export, diagnostics linked to lines, and autosaved drafts.
- **Rendering:** scene selection, independent resolution and frame-rate controls, custom output settings, progress, and cancellation.
- **Preview and history:** MP4 playback, video export, named output folders, render logs, and saved preferences.
- **Interface:** dark/light themes, keyboard navigation, accessible dialogs, and a guided first-run tour.
- **Equation engines:** standard LaTeX support for `Tex` and `MathTex`, plus Typst for `Typst` and `MathTypst`.
- **Compact runtime:** Python 3.12, Manim Community 0.21.0, Cairo, minimal TeX, Typst, and audio tools. Studio uses shared Evergreen WebView2 rather than a private browser copy.
- **Future updates:** optional automatic checks, SHA-256 verified downloads, and installation that preserves saved work.

The app's shipped files occupy approximately 695 MB; the portable ZIP is approximately 263 MB. This excludes user data, generated caches, and the shared WebView2 installation.

## Downloads

- **Setup-x64.exe:** downloads and prepares the rendering engine; internet required.
- **Offline-Setup-x64.exe:** includes rendering tools and the WebView2 prerequisite for offline installation.
- **Portable-x64.zip:** extract the entire ZIP and open **Manim Studio.exe**. First launch needs internet only if WebView2 is absent.
- **Third-Party-Sources.zip:** matching component sources and original build recipes, including Typst's native Rust dependencies.
- **SHA256SUMS.txt:** SHA-256 checksums for the four downloads.

All app downloads include minimal TeX plus Typst. Standard rendering works offline after setup. Online setup includes the verified TeX snapshot and downloads locked Python packages separately.

## Requirements and limits

Requires 64-bit Windows 10 (2004+) or Windows 11. Studio executables are unsigned. Scripts execute with your Windows account's permissions; review code before rendering.

The included TeX profile supports standard Manim equations but excludes XeLaTeX, LuaLaTeX, bibliography processing, and general publishing utilities. Custom workflows may require a separate full TeX installation. Typst uses its own syntax; LaTeX scripts do not need conversion in this edition.
