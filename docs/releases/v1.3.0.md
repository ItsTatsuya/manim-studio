Create several videos from PDFs, manage a render queue, and recover from script errors in one workspace.

## What's changed

- feat(queue): start, pause, reorder, or cancel queued videos, with preferences for when to start and how to handle failures
- feat(projects): turn multiple PDFs into videos with separate chats, scripts, narration, and assets in shared or separate folders
- feat(render): send script errors back to the same chat and retry automatically, with up to three repair attempts
- perf(render): render supported long scenes with up to four helpers and fall back to a single process when needed
- perf(narration): generate narration while the animation renders and reuse finished work on retries
- feat(providers): view remaining Codex and Claude plan limits reported by your signed-in CLIs
- feat(workspace): use a compact sidebar with project search and quick access to settings, renders, usage, and updates
- feat(updates): read release notes in the sidebar and Settings before downloading an update
- fix(packaging): include every rendering module so installed and portable builds can render videos
- fix(narration): use Standard voice quality for new projects to match the voice offered during setup
- fix(onboarding): show readable spacing beside the voice download size
